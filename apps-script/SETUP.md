# 비북스의 미래 — 포스트잇 벽 연결하기

지금 페이지는 **체험 모드**입니다. 방문자가 붙인 메모가 그 사람 브라우저에만 저장됩니다.
아래처럼 연결하면 모든 방문자가 같은 벽을 함께 채웁니다.

1. 구글 시트를 새로 만듭니다 (예: `비북스의 미래 (포스트잇)`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열고, `Code.gs` 내용을 그대로 붙여 넣습니다.
3. 함수 목록에서 `setup`을 한 번 실행합니다 (권한 허용). `미래` 탭과 머리글이 생깁니다.
4. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
5. 나온 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 `index.html`의 `var FUTURE_API = '';` 따옴표 안에 넣고 다시 올립니다.

## 검수
- 시트의 `숨김` 칸에 `Y`를 적으면 그 메모는 벽에서 바로 내려갑니다.
- 링크가 들어간 메모, 같은 문장 반복(10분), 10분에 40장 넘는 폭주는 자동으로 막습니다.
- 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 올리면 URL이 그대로 유지됩니다.
